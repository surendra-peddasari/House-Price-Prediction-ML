# Data

The raw Ames housing dataset is intentionally not committed to this repository.

The main notebook downloads the project-provided archive automatically:

`https://d3ilbtxij3aepc.cloudfront.net/projects/CDS-Capstone-Projects/PRCP-1020-HousePricePred.zip`

When the notebook is executed, the archive is stored under `data/` and extracted under `data/raw/`.

Those generated files are ignored by Git through `.gitignore`.
