# Project Requirements — PRCP-1020-HousePricePred

This document summarizes the supplied project brief.

## Problem Statement

The project requires:

1. A complete data analysis report.
2. A robust machine-learning algorithm for predicting house prices from market/property factors.
3. Analysis of the relationship between house features and price.
4. Customer recommendations based on area, price and other requirements.
5. A model comparison report and production-model recommendation.
6. A challenges report explaining the data problems, techniques used and reasoning.

## Dataset

The project brief describes an Ames, Iowa residential housing dataset with 79 explanatory variables. `SalePrice` is the target variable.

The attributes cover property class/zoning, lot characteristics, neighborhood, quality/condition, construction year, remodeling, basement, living area, bathrooms, bedrooms, kitchen, garage, outdoor features and sale information.

## Practice Skills

- Creative feature engineering
- Advanced regression techniques such as Random Forest and Gradient Boosting

## Submission Requirement

The brief states that all tasks must be created in a **single Jupyter notebook** and that the notebook should be included in the final submission.

The repository therefore keeps `notebooks/House_Price_Prediction.ipynb` as the main project deliverable.
